# 单词伙伴（Word Buddy）：离线英语单词训练器

单词伙伴把 FoloToy AI Passport（ESP32-C3、240 x 320 竖屏、三个按键、无触摸）变成面向中国小学生的随身英语单词训练器。
孩子每次练一组五个词（微练习）：新词做“二选一看义”，熟悉的词用闪卡诚实自评，已经能回想的词做自然拼读填空。
间隔重复算法决定每个词什么时候再出现。全部功能在设备上离线运行：不联网、不用麦克风、不做云端评分。
界面文字为简体中文；单词、例句和音标为英文。

本 README 只介绍 `feature/vocab-trainer` 分支上的应用。上游项目总览见 [docs/README.zh_CN.md](docs/README.zh_CN.md)。
架构、设计决策和词库数据契约见[单词伙伴设计文档](docs/assets/word-buddy-design.zh_CN.md)；
素材来源、许可与重新生成命令见 [assets/README.zh_CN.md](assets/README.zh_CN.md)。

## 一览

| 项目 | 单词伙伴 |
| --- | --- |
| 学习者 | 6-12 岁、母语为普通话、学习小学英语的孩子 |
| 一组练习 | 主页按一次 OK 开始一组 5 个词的微练习（含检查卡最多 10 张卡，约 2-3 分钟） |
| 阶段 | 1：为英文单词选择中文意思；2：闪卡自评；3：补全缺失的发音字母块 |
| 学习模型 | 熟练度 0-5 级，按已完成的练习组数计算间隔重复（设备没有实时时钟） |
| 激励 | 经验值、十个带称号的等级、会孵化和长大的宠物；没有饥饿或难过状态 |
| 词库 | 内置测试词库 48 条（40 个单词、8 个短语），英式音标；34 条带自然拼读数据 |
| 声音 | 合成提示音；只有带私有音频包的本地构建才会朗读单词（否则用视觉替代）；音量 80 % / 30 % / 静音 |
| 电源 | 无按键 20 秒变暗、30 秒熄屏、150 秒深度睡眠；任意键唤醒 |
| 存储 | 进度保存在 NVS 中，只在保存点且没有声音播放时写入 |
| 连接 | 无：从不初始化 Wi-Fi 和蓝牙 |

## 一组练习怎样进行

界面文字为中文。下文直接给出屏幕上的原文；字符串全部定义在 `main/vocab_strings.h`。

### 主页

开机和从深度睡眠唤醒后显示主页，不发出任何声音。主页显示宠物、等级称号、经验条和“经验 45/90”、
“已学 12 个 · 掌握 3 个”、可能出现的提示行，以及“按 ● 开始挑战”。状态栏显示等级（“Lv.n”）、
电量百分比、音量图标和电池图标。按 OK 开始一组练习。

### 怎样选出五个词

一组最多五个词（只有词库更小时才更少）：

1. 先选到期需要复习的词，逾期最久的优先。
2. 再按词库顺序（即课程顺序）加入新词：通常每组一到三个，只要还有新词就至少一个。
   新设备没有到期的词，所以会拿到五个新词。
3. 如果还有空位，就提前复习最快到期的词，保证孩子随时都能练习。
4. 选出的词打乱顺序。

### 三个阶段

单词的熟练度决定卡片类型：

| 熟练度 | 含义 | 卡片 |
| --- | --- | --- |
| 0 | 新词 | 阶段 1：看义二选一 |
| 1 | 见过 | 阶段 2：闪卡，正面显示单词 |
| 2 | 熟悉 | 阶段 2：闪卡；能播放单词音频时，正面显示挖空的例句 |
| 3-5 | 能回想、能拼写、已掌握 | 有自然拼读数据时为阶段 3 拼读填空，否则为阶段 2 |

**阶段 1：认识单词。** 卡片显示英文单词、灰色音标行和“它是什么意思？”，同时播放单词读音。
两个面板分别在 ▲（UP）和 ▼（DOWN）旁显示一个中文意思。按所选意思旁边的键作答；按 OK 重听。
错误选项总是来自另一个类别（例如交通工具而不是水果），并且只以中文显示，绝不显示英文。

- 答对：所选面板变绿，显示“答对了！”并播放明亮的提示音；0.6 秒后进入下一张卡。
- 答错：进入[错题停留](#错题停留)。

**阶段 2：回想单词。** 正面只显示单词（熟练度为 2 且单词音频能播放时，显示用 `____` 代替单词的例句，
例如 `I eat an ____.`），播放读音，并提示“想一想：什么意思？”（例句正面为“听一听：空里填什么？”）。
前一秒按键无效（提示“想一想…”），让孩子真正尝试回忆；之后按任意键翻面（提示“按任意键翻面”）。
背面显示单词、中文意思和例句：

- ▲“认识，下次见”：诚实自评。
- ▼“忘了，等下考我”：屏幕显示“好，等下再考你”，这个词在两张卡之后以阶段 1 检查卡的形式再出现，绝不会立刻出现。
- OK：再听一遍。

**阶段 3：拼写单词。** 卡片显示中文意思和缺了一个发音字母块的单词，例如带闪烁空格的 `b _ s`，
提示“选字母，填空格”；▲ 和 ▼ 提供两个字母块，例如 `u` 和 `a`。按 OK 重听整个单词。

- 答对：空格以绿色填入正确字母块，完整单词出现，播放欢呼音，显示“拼对了！”；1.2 秒后进入下一张卡。
- 学习卡第一次答错：空格晃动，显示“再想想，再试一次”，停顿 0.6 秒后再答一次。
- 第二次答错，或检查卡第一次答错：揭示正确字母块，显示“记住正确的拼写”，随后进入错题停留。

屏幕上绝不出现拼错的英文单词。字母块只单独出现在自己的选项面板里；空格里要么为空，要么是正确的字母块。

### 错题停留

答错后，错误选项立即消失，正确选项变绿，徽标显示“记住它”，提示“记住它的意思”，
先播放柔和的低音提示，再播放单词读音。1.5 秒内所有按键都无效（音量长按除外）。
之后提示“按 ▲ 继续”或“按 ▼ 继续”：只有正确的键能继续，另一个键只会让正确面板轻轻跳动，按 OK 重听。
成绩在第一次按键时就已确定。

### 检查卡

- **等下考我。** 在阶段 2 背面按“忘了”，会在两张卡之后加入这个词的阶段 1 检查卡（徽标“再考一次”）。
  检查卡答错时，这个词回到熟练度 0。
- **突击检查。** 连续三次“认识”会立即加入一张检查卡，先显示 0.8 秒“突击检查！”和“刚才的词，还记得吗？”。
  它检查刚才自评“认识”的某个词，但不会是最后一个（它的意思刚刚还在屏幕上）。
  答对则自评有效；答错则被查的词降级，同一轮中其他“认识”的自评全部作废，这些词下一组就会再出现。
- **太简单。** 在新词（阶段 1 题目）或闪卡正面长按 UP，当前卡结束并显示“好，等下考考你！”。
  两张卡之后先显示“太简单？考考你！”和“答对就直接满级”，再出一张检查卡：词有自然拼读数据时为阶段 3，否则为阶段 1。
  答对则该词直接满级，30 组之后再复习；答错则熟练度最多为 1，下一组再出现。

每个词每组最多加入一张检查卡，所以一组永远不超过 10 张卡。状态栏以“n/N”计数；加入检查卡后 N 立即增加。

### 暂停

在卡片上、按键未被锁定时长按 OK，打开暂停卡：“休息一下”“要继续吗？”，▲“继续学习”，▼“回到主页”。
按 UP 或 OK 回到同一张卡。按 DOWN 结束本组：已经作答的结果保留并保存，但本组不算完成，
因此不得经验，也不推进复习进度。

### 小结

最后一张卡之后显示“太棒了！”、成绩“答对 x/y”（第一次就答对的数量 / 题目与检查卡的作答数量；
本组没有这类题目时显示“学完 N 个词”）、“+N 经验”、经验条，以及宠物吃零食并跳跃。
升级时还会显示“升级啦！”加新称号，播放更长的升级音效，宠物换上新外观并跳三下。
前 0.8 秒按键无效；之后按 ● 再来一组，按 ▲ 或 ▼ 回到主页，并停止仍在播放的声音（提示“● 再来一组  ▲ 回主页”）。

### 经验、等级与宠物

- 完成一组得 5 点经验，阶段 1、阶段 3 或检查卡每次第一次就答对再加 1 点，每个首次掌握的词再加 2 点。
  自评“认识”不得经验，因为没有经过验证。中途放弃的一组不得经验。
- 等级按累计经验：Lv1 0、Lv2 30、Lv3 90、Lv4 180、Lv5 300、Lv6 450、Lv7 630、Lv8 840、
  Lv9 1080、Lv10 1350（最高级，经验继续累计）。称号依次为：单词新手、单词学徒、单词探险家、
  单词小勇士、单词小达人、单词高手、单词明星、单词冠军、单词大师、单词之王。
- 宠物在 Lv1 是一颗蛋，Lv2-3 是蓝色幼崽，Lv4-6 是带粉色脸颊的绿色小孩，Lv7-9 是长出耳朵的紫色成体，
  Lv10 戴上王冠。它在主页轻轻上下浮动并眨眼，每次小结都会吃东西。它永远不会饿，也不会难过。

### 间隔重复简述

设备没有实时时钟，所以时间按已完成的练习组数计（练习计数）。第一次就答对会让词升一级，
并按新等级在 1、2、5、10 或 20 组之后安排复习（对应 1-5 级）；答错则下一组就到期。
全部结果规则见[设计文档](docs/assets/word-buddy-design.zh_CN.md#5-学习模型)。

## 按键

UP（▲）、DOWN（▼）和 OK（●）共用一条电阻分压按键线。单击是短按，在松开后约 180 毫秒才上报。
同一个键快速按两次（第二次在第一次松开后约 0.2 秒内按下）算一次单击。长按在 500 毫秒时触发一次，之后不会再有单击。

| 状态 | UP 单击 | DOWN 单击 | OK 单击 | UP 长按 | DOWN 长按 | OK 长按 |
| --- | --- | --- | --- | --- | --- | --- |
| 主页 | - | - | 开始一组 | - | 音量 | - |
| 阶段 1 题目 | 选上面的意思 | 选下面的意思 | 重听 | 太简单（新词卡） | 音量 | 暂停 |
| 错题停留前 1.5 秒 | - | - | - | - | 音量 | - |
| 错题停留等待中 | ▲ 正确则继续，否则面板跳动 | ▼ 正确则继续，否则面板跳动 | 重听 | - | 音量 | 暂停 |
| 阶段 2 正面前 1 秒 | - | - | - | 太简单（学习卡） | 音量 | 暂停 |
| 阶段 2 正面之后 | 翻面 | 翻面 | 翻面 | 太简单（学习卡） | 音量 | 暂停 |
| 阶段 2 背面 | 认识 | 忘了，等下考我 | 重听 | - | 音量 | 暂停 |
| 阶段 3 题目 | 填 ▲ 字母块 | 填 ▼ 字母块 | 重听 | - | 音量 | 暂停 |
| 反馈、横幅、阶段 3 重试停顿 | - | - | - | - | 音量 | - |
| 暂停卡 | 继续 | 结束本组，回主页 | 继续 | - | 音量 | - |
| 小结前 0.8 秒 | - | - | - | - | 音量 | - |
| 小结之后 | 回主页 | 回主页 | 再来一组 | - | 音量 | - |
| 熄屏 | 仅唤醒 | 仅唤醒 | 仅唤醒 | 仅唤醒 | 仅唤醒 | 仅唤醒 |
| 词库错误 | - | - | - | - | 音量 | - |

`-` 表示忽略。检查卡的行为与所在阶段相同，但不接受“太简单”。

输入防护让条件反射式的连按和按键抖动不会跳过单词：

- 每张新卡、每次翻面、停留开始与结束、每个横幅和屏幕都开启新的输入周期：清空排队的按键事件，
  在周期开始前就按下的键不会作用于新屏幕。
- 新屏幕出现后 250 毫秒内按下的 UP、DOWN 单击被忽略。
- 双击按第一次按下来判断：在上一张卡就开始的双击不会作用于新卡，250 毫秒的规则也从第一次按下算起。
- 短于 30 毫秒的单击被忽略；同一个键长按松开后 120 毫秒内再次按下视为抖动。
- 另一个键还按着时开始的按压被忽略：在共用的分压按键线上，这只可能是长按时触点抖动产生的幻影按键。
- 对双击，这些规则会同时考虑两次按压：至少有一次按压不短于 30 毫秒才算数；如果它是长按后的抖动，
  或任一次按压开始时另一个键还按着，就被忽略。

## 声音与音量

- 卡片出现、翻面以及每次按 OK 重听时播放单词读音。简短的合成提示音标示事件：明亮的两音“答对”、
  柔和的低音“答错”（绝不是蜂鸣）、翻面滑音、自评和音量变化时的“嘀”声、阶段 3 答对和小结时的欢呼，
  以及升级时更长的音效。开机、唤醒和主页都不发声，放在书包里或教室里也保持安静。
- 在任何地方（包括锁定期间）长按 DOWN，音量按 80 % -> 30 % -> 静音 -> 80 % 循环。
  浮动提示显示“音量：大”“音量：小”或“静音” 1.2 秒，状态栏图标随之改变（静音时为橙色）。
  音量会被记住，在下一个保存点写入；新设备从 80 % 开始。
- 静音时完全不向扬声器输出。本应播放单词音频时，英文单词、例句或单词骨架改为变黄并加下划线 0.6 秒，
  重听提示由“● 再听一遍”变为“● 再看一遍”。没有单词音频时阶段 2 正面不使用挖空例句，因为要靠读音才能确定是哪个词。
- 不带私有音频包的构建（从干净检出构建的所有固件，包括 CI）在单词上也是这样：每个单词读音都由视觉替代和“● 再看一遍”取代，
  提示音和音量控制照常工作。
- 如果音频硬件启动失败，单词伙伴静音运行并显示暗色的静音图标，长按 DOWN 显示“声音不可用”。

## 电源与电池

| 距离上次按键 | 行为 |
| --- | --- |
| 20 秒以内 | 背光 80 % |
| 20 秒 | 背光 20 %；按键照常工作并恢复 80 % |
| 30 秒 | 停止声音、保存进度、关闭背光；屏幕保持原状态 |
| 150 秒 | 有变化时再保存一次，然后进入深度睡眠 |

- 熄屏时，任意键的第一次按压只会点亮屏幕：直到这次按压松开 0.4 秒后，任何按键都不起作用，然后继续同一张卡。
  用双击唤醒也只会唤醒：第二次按压会让这 0.4 秒重新计时。
- 深度睡眠只能用按键唤醒（没有定时唤醒）。设备重启到主页，用来唤醒的那次按压不起作用。
  未完成的一组会丢失，但它的作答结果在熄屏时已经保存。
- 有键按着时深度睡眠会等待（按着的键会让芯片立刻醒来），每 5 秒重试一次。
- 状态栏显示电池图标，电量不高于 15 % 时为红色。主页还显示电量百分比，不高于 10 % 时显示“电量低，请充电”。
  不高于 5 % 时每张卡结束后也会保存进度。读不到电量计时图标为暗色，主页显示 `--%`。

## 进度存储与烧录

- 进度保存在 NVS 分区（24 KB）的命名空间 `vocab` 中：一条 `meta` 记录（练习计数、经验、音量、累计统计）
  和若干进度块 `p00`、`p01`……，每个词一条 6 字节记录（熟练度、下次到期的练习计数、是否见过、是否曾经掌握、出错次数）。
  每个数据块都带格式版本号和 CRC-32。记录按单词 uid 与词库匹配，因此将来换用新词库时，仍在库中的词会保留进度。
- 保存点：小结、熄屏、暂停后回主页、深度睡眠前，以及电量不高于 5 % 时每张卡结束后。
  保存前先停止声音并最多等待 2 秒，直到扬声器空闲；仍在忙则推迟到下一个保存点。
  只写入有变化的进度块，最后写 `meta`，一次提交。
- 单词伙伴从不自行擦除存储。如果 NVS 无法初始化、保存失败，或存储的数据来自更新的固件格式，
  它就只在内存中继续工作，主页显示“进度暂时无法保存”。损坏的进度块只重置它自己包含的词。
- 本版本没有重置菜单（有意的决定）。要从头开始，必须重写 NVS 区域，例如烧录合并镜像。

### 烧录会保留还是重置进度

烧录设备需要设备主人同意。请遵循仓库的[烧录与已存数据规则](docs/development/engineering/firmware-layout.zh_CN.md#烧录与已存数据)；
烧录前不需要备份设备上原有的固件。

- 经过验证的合并镜像 `build/FoloToy-AI-Passport-full.bin` 从 `0x0` 写入。它同时覆盖 NVS 区域（0x9000-0xEFFF），
  因此烧录它会**重置孩子的学习进度**：经验、等级、宠物、每个词的熟练度和音量。它适用于空白设备或有意的重新开始。
- 要保留进度，只写入 NVS 以外的镜像（分区布局必须保持不变）：
  - 把经过验证的固件归档中的应用镜像写到 `0x10000`：
    `python -m esptool --chip esp32c3 -p <port> -b 460800 write-flash 0x10000 build/firmware/<sha256>/FoloToy-AI-Passport.bin`；
  - 或用 `idf.py -p <port> flash` 分段烧录，它分别写入 bootloader、分区表和应用。它在仓库根目录用根目录的 `sdkconfig` 构建，
    而默认配置变化时该文件会保留旧值：请确认它带有本分支的设置（LVGL 内存池 48 KB、关闭蓝牙），
    或按[构建与验证](docs/development/engineering/build-and-test.zh_CN.md)中的说明重新生成。
- `idf.py erase-flash` 会擦除全部进度，不要作为常规步骤。

## 构建与验证

使用 ESP-IDF 5.5.3（见[环境引导](docs/development/engineering/environment-setup.zh_CN.md)和[构建与验证](docs/development/engineering/build-and-test.zh_CN.md)）：

```bash
./tools/validate.sh --static     # 仓库检查、工作流检查和全部主机测试
./tools/validate.sh --firmware   # ESP-IDF 构建、0x0 合并镜像、布局校验、调试归档
./tools/validate.sh              # 两者都运行；需要已激活的 ESP-IDF 5.5.3 环境
```

对单词伙伴，静态门禁会编译并运行 C 主机测试 `tests/test_vocab_*.c`（词库、间隔重复、输入过滤、空闲时间线、
持久化编解码与存储、经验与宠物、布局、练习流程、系统级模拟、三个阶段、干扰项选择、防敷衍检查、填空校验、
ADPCM 解码与音频包解析、提示音合成）、黑盒 QA 系统测试 `tests/test_vocab_qa_*.c`（多日使用、精确时序流程、电源与持久化、
边界情况、带英文安全扫描的模糊测试），以及三个 Python 检查：`tests/test_vocab_contract.py`（固件源文件、
LVGL 对象生命周期、无网络代码、不擦除 NVS、深度睡眠顺序）、`tests/test_vocab_fonts.py`（字形覆盖与字体结构）和
`tests/test_vocab_clips.py`（音频包格式与提交的空音频包；有本地音频包时还检查其时长与响度）。
无论有没有私有音频包，这些测试都能通过。固件门禁把经过验证的镜像放在 `build/FoloToy-AI-Passport-full.bin`，
并在 `build/firmware/<sha256>/` 下保存配套的调试归档。应用镜像带本地音频包时约 1.15 MB，不带时约 0.9 MB，只占 8 MB Flash 的一小部分。

迭代时可以单独运行一个主机测试（每个测试的完整源文件列表见 `tools/validate.sh`）：

```bash
mkdir -p build/host
cc -std=c11 -Wall -Wextra -Werror -Imain \
  tests/test_vocab_srs.c main/vocab_srs.c main/vocab_bank.c main/vocab_rng.c main/vocab_view.c \
  -o build/host/test_vocab_srs
build/host/test_vocab_srs
```

素材检查只需要 Python 标准库：

```bash
python3 tools/vocab_fonts.py --check
python3 tools/vocab_audio/build_clips.py --check
```

字体、音频和常用词表只能用 [assets/README.zh_CN.md](assets/README.zh_CN.md) 中记录的命令重新生成。
新增或修改任何中文界面字符串或词库条目后都必须重新生成字体，否则字体检查会失败。

### 原生 Windows

`tools/validate.sh` 是 Bash 脚本。在 Git Bash 等 POSIX shell 中，只要 C11 编译器可用作 `cc`、Python 3 可用作 `python3`，
并且 `actionlint` 在 `PATH` 中或由 `ACTIONLINT_BIN` 指定（自动下载 actionlint 只支持 Linux 和 macOS），就可以运行静态门禁。
ESP-IDF 工具拒绝在 Git Bash 等 MSYS shell 中运行，因此请在已激活 ESP-IDF 5.5.3 的 PowerShell 中执行 `run_firmware_checks`
的固件步骤（或使用 WSL2，或环境引导中的 Docker 方式）。在仓库根目录、使用全新的构建目录执行
（要得到不含私有音频的镜像，在构建命令中加上 `-D VOCAB_NO_CLIPS=1`，见下文）：

```powershell
$root = (Get-Location).Path -replace '\\', '/'
$b = "$root/build/fw-validate"
$env:SDKCONFIG_DEFAULTS = "$root/sdkconfig.defaults"
idf.py -B $b -D "SDKCONFIG=$b/sdkconfig" build
idf.py -B $b merge-bin -o "$b/FoloToy-AI-Passport-full.bin"
python tools/verify_firmware.py $b
python tools/archive_firmware.py create $b --archive-root "$root/build/firmware"
Copy-Item "$b/FoloToy-AI-Passport-full.bin" "$root/build/FoloToy-AI-Passport-full.bin"
```

### 构建中的单词音频

单词音频是私有的本地产物，Git 会忽略它。`main/CMakeLists.txt` 在配置构建目录时选择嵌入哪个音频包：

| 情况 | 嵌入的音频包 | 结果 |
| --- | --- | --- |
| `assets/audio/vocab_test_clips.bin` 存在且未设置 `VOCAB_NO_CLIPS` | 本地测试音频包 | 会朗读单词；固件必须保密 |
| 没有本地音频包（干净检出、CI），或使用了 `-D VOCAB_NO_CLIPS=1` | 提交的空音频包 `assets/audio/vocab_clips_empty.bin` | 没有单词音频：用视觉替代和“● 再看一遍”；提示音照常播放 |

- 配置日志中以 `Word Buddy clips: embedding` 开头的一行说明了选择结果。分享任何固件镜像之前都要先检查这一行。
- 选择在配置阶段完成。生成或删除本地音频包后，请使用全新的构建目录或运行 `idf.py reconfigure`。
  `./tools/validate.sh --firmware` 总是使用全新的目录，因此只要工作区里有本地音频包，就会把它嵌入。
- `-D VOCAB_NO_CLIPS=1` 会保存在该构建目录的 CMake 缓存中。撤销方法：`idf.py -D VOCAB_NO_CLIPS=0 reconfigure`、
  `cmake -U VOCAB_NO_CLIPS <构建目录>`（在已激活的 ESP-IDF 环境中），或使用全新的构建目录。
- 生成本地音频包需要装有离线语音 Microsoft Zira Desktop 的 Windows；命令见 [assets/README.zh_CN.md](assets/README.zh_CN.md)。
  用本地音频包构建的固件绝不能发布或再分发：不上传社区、不作为发布附件、不作为文件分享。

### 未来词库的数据契约

把用户提供的词表转换成固件数据的工具已延后，目前还不存在。固件已经确定了它必须产出的内容，
因此将来的词库可以替换测试词库，除下述容量限制外无需改代码：

| 字段 | 规则 |
| --- | --- |
| `uid` | 16 位、非零、唯一且永久不变；绝不复用或重新编号，因为进度和音频都以它为键 |
| `text` | 英文，可打印 ASCII，1-20 个字符，首尾无空格；含空格即为短语 |
| `ipa` | 用支持的符号书写、两端带斜杠的英式宽式音标，或为空 |
| `zh` | 中文意思，1-6 个汉字 |
| `category` | 从 1 开始的类别编号；阶段 1 从其他类别中取错误意思 |
| `cloze_pos`、`cloze_right`、`cloze_wrong` | 全有或全无：两个等长、1-3 个小写字母的字母块，构成允许的近音对；错误拼写不得构成真实单词或词库中的词 |
| `example` | ASCII，最多 30 个字符，恰好包含一次 `text` |
| `example_cloze` | 把 `example` 中的 `text` 换成 `____` 的句子，或为空 |
| `example_zh` | 保留字段，始终为空 |
| 音频 | 不放在条目里：每个 uid 在音频包中对应一段音频 |

表中顺序就是课程顺序。当前固件最多跟踪 256 条（`VOCAB_RECORDS_MAX`）；更大的词库会显示词库错误界面，
直到提高这个上限。每个新字符还都需要重新生成字体。完整契约（填空规则、音频格式、校验步骤和容量限制）见
[设计文档](docs/assets/word-buddy-design.zh_CN.md#13-延后流水线的词库数据契约)。

## 离线与隐私

- 不联网：从不初始化 Wi-Fi 和蓝牙，`sdkconfig.defaults` 中禁用了蓝牙，应用组件（`main`）不依赖任何无线或网络组件，
  并且固件源文件一旦出现网络代码，`tests/test_vocab_contract.py` 就会失败。
- 不用麦克风：单词伙伴只播放声音，从不读取音频输入。通过云服务给口语发音打分的功能已永久取消。
- 没有账号、统计上报或云同步：学习数据（熟练度、经验、统计）只保存在设备的 NVS 中。
- 单词音频（如果有）在电脑上离线生成，并且不放进仓库；运行时不合成、也不下载任何内容。

## 已知限制

- 还没有任何内容在真机上验证（见[验证状态](#验证状态)）。
- 只有 48 条测试词库；用户词库流水线已延后。
- 从仓库构建的固件（包括 CI）没有单词音频：私有测试音频只在本地。单词使用视觉替代，这类构建中也不会出现阶段 2 的挖空例句正面。
- 本地测试音频是美式英语语音，而音标是英式（测试阶段已接受）。
- 阶段 3 重听的是整个单词；/b/ /ʌ/ /s/ 这样的分音素读音已延后。
- 意思只用中文文字显示；图片和图标已延后。
- 没有跟读模式、家长菜单、多用户，也没有进度重置功能（只能重新烧录合并镜像）。
- 复习按已完成的练习组安排，而不是按天：设备不用时，单词不会变成到期。
- 音量设置在下一个保存点写入，不是立即写入。
- 中途放弃的一组会保留作答结果，但不得经验，也不算一组。
- 同一个键快速连按三次或更多次完全不会产生单击：按键驱动只上报单击和双击。孩子是否会察觉到这一点，需要在真机上检查。
- 电量读数依赖 CW2017 电量计参数，未经校准。
- 当前固件最多跟踪 256 条词库条目；24 KB 的 NVS 分区适合约 1200 个词（见设计文档）。

   包括最长的布局（*Good morning* 的单词骨架、*Nice to meet you*、两行的挖空例句、带两行例句的阶段 2 背面）；
   音标行中 a 与 ɑ 能区分。
5. 带本地音频包时：单词音频和提示音在 80 % 与 30 % 音量下清晰播放，保存前后也没有爆音；静音时完全无声；图标与音量一致；
   提示音与单词音量均衡；播放没有断续。带空音频包时：每个单词都显示视觉替代，提示音照常播放。
6. 进度、练习计数、经验和音量在断电重启和深度睡眠唤醒后仍保留（使用保留 NVS 的烧录方式）。
7. 20 秒变暗、30 秒熄屏、150 秒深度睡眠；按键唤醒回到主页且唤醒的那次按压无效；按住按键时推迟深度睡眠；
   测量深度睡眠电流。
8. 用真实电量计读数检查电池图标阈值和主页提示；在主页上，音量浮动提示取代开始提示行，之后开始提示行重新出现。
9. 启动日志中的内存数据：`widgets created` 行和每个屏幕的首行（LVGL 内存池最大空闲块不小于 4 KB、
   空闲堆不小于 40 KB、应用任务栈），以及音频任务的栈高水位。
10. 动画：宠物待机与眨眼、进食与跳跃、升级换色及升级音效、面板跳动、确认闪烁。
11. 真实按键线上的输入：长按时没有幻影按键；双击只作答一次；用双击唤醒只会唤醒；在上一张卡开始的双击对新卡不起作用；
    新卡出现时的条件反射按键被忽略。
